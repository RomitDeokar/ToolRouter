# ToolRouter

## Semantic Tool Retrieval for MCP Agents

ToolRouter is a semantic retrieval layer for MCP agents. Instead of exposing every tool to an LLM, it retrieves only the most relevant tools before reasoning.

## Core Features
- Generic MCP Manifest Parser
- Semantic Tool Retrieval
- Adaptive Confidence Gate
- Explainability
- CommerceBench Evaluation Suite

## v1 Scope
- Manifest parser
- Dense retrieval
- Confidence gate
- Explainability
- Benchmark

## Not in v1
- Frontend
- Authentication
- SaaS
- Multi-agent orchestration
- Plugin marketplace
- Voice
