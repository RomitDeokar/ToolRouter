# Project Specification

## Goal
Build a semantic retrieval layer for MCP agents.

## Deliverables
1. Generic Manifest Parser
2. Tool Index
3. Dense Retrieval
4. Confidence Gate
5. CommerceBench

## Non Goals
- UI
- Deployment
- Authentication
- User management
- Workflow engine

## Constraints
- Python-first
- Local execution
- Generic for any MCP manifest
